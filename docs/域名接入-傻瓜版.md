# wenhh.top 接入 GRF —— 手把手（不用填 IPv4）

## 先回答你卡住的那个问题

**那个 "IPv4 地址（必填）" 的框，不要填，直接关掉这个弹窗。**

为什么？
- A 记录的作用是：把域名指向一个**固定的公网 IP**。
- 你家宽带没有固定公网 IP（运营商给的是动态的、甚至是大内网 IP），所以这个框里
  填任何数字都是错的，填对了也是过一会儿就失效。
- 我们用的是 **cloudflared 隧道**：由你电脑**主动向外**连到 Cloudflare，
  流量再从 Cloudflare 顺着这条已经建好的连接送回来。
  它**根本不需要**知道你家的 IP，所以**不需要 A 记录**。

一句话：你不该加任何 DNS 记录。这个页面可以整个忽略。

---

## 你真正要做的只有 3 步

### 第 1 步：在 Cloudflare 把域名加进去（加 site，不是加记录）

1. 登录 https://dash.cloudflare.com
2. 点右上角 **Add a site**（添加站点）
3. 输入 `wenhh.top` → Continue
4. 选 **Free**（免费计划）→ Continue
5. Cloudflare 会扫描已有 DNS 记录，**扫不到东西是正常的，直接 Continue**
6. 最后它会给你**两条名称服务器地址**，长这样（你的会和下面不一样）：
   ```
   xxxx.ns.cloudflare.com
   yyyy.ns.cloudflare.com
   ```
   **把这两条抄下来。**

> 找不到这两条了？在 Cloudflare 面板点进 `wenhh.top`，
> 看 **Overview（概览）** 页右侧，标题是 **"Cloudflare 名称服务器"**，
> 下面就是那两条。状态会显示 "待激活 / Pending"。

### 第 2 步：去新网，把 DNS 服务器换成那两条

1. 登录新网（myhostadmin.net）域名控制台
2. 找到 `wenhh.top` → **管理 / DNS 设置 / 修改 DNS 服务器**
3. 把原来的
   `ns1.myhostadmin.net` / `ns2.myhostadmin.net`
   删掉，换成第 1 步抄下来的两条 Cloudflare NS
4. 保存

### 第 3 步：等生效（几分钟到 24 小时）

Cloudflare 概览页的状态会从 **"待激活" → "活动 / Active"**。
在 Windows 里自己查：

```powershell
Resolve-DnsName wenhh.top -Type NS -Server 8.8.8.8
```

只要结果里出现 `ns.cloudflare.com` 就成了。

## 现在就想用？

不用等域名。临时地址现在就能用，功能一模一样：

**https://arg-specializing-unnecessary-scene.trycloudflare.com**

缺点只有两个：进程重启后地址会变、不好长期分享给别人。
自己用完全够了。

## 常见误解对照表

| 你可能以为 | 实际情况 |
|---|---|
| 要填 IPv4 才能用域名 | 不需要，隧道模式下没有任何 IP 需要填 |
| 加个 A 记录指向本机就行 | 你家没公网 IP，指向本机也访问不到 |
| 加个 CNAME 指向 trycloudflare 地址就行 | 免费版 Cloudflare 不支持这种"部分接入"，必须整域迁 NS |
| 迁 NS 会不会把网站搞坏 | 现在这个域名本来就没解析到任何东西，迁过去只会变好 |
| 迁 NS 要重新备案/重新买 | 不用，域名还是你的，只是换了解析服务商 |
